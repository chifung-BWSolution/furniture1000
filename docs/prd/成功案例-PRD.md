> 2. 本倉庫實際程式碼（`src/components/dashboard/cases/`、`src/lib/caseShowcase.ts`、`supabase/functions/fetch-bwa-works/`、`supabase/functions/_shared/caseShowcase.ts`）。

## 1. 模組定位

### 1.1 一句話定位

成功案例＝**內部同事的案例工作台**：查看 PMS 真實訂單與交付記錄，從中**挑選一部分**整理成**對外文件**給客戶看。

### 1.2 內外分界（已確認）

| 面 | 內容 | 資料 |
|---|---|---|
| 內部（三個頁面） | 訂單數據、完工相片、知名客戶；供同事查閱、搜尋、篩選 | PMS 即時資料，FDS 不複製、不落庫 |
| 對外（導出文件） | 精選訂單／案例／相片／客戶 Logo 組成的文件，交給客戶 | 由同事導出前**逐項挑選並可修改**，只含安全欄位 |

內部頁面**不是**客戶直接可見的頁面；客戶看到的只有導出成品（以及日後客戶專區的成功案例頁，見 §8 待確認）。

## 2. 現況（程式碼確認，2026-10-23）

### 2.1 頁面與入口

| 頁面 | ViewType | 檔案 | 內容 |
|---|---|---|---|
| 訂單數據 | `fds2-cases-orders` | `CaseOrdersPage.tsx` | PMS `bwf_orders` 按項目分組的表格：項目、PM、產品數、總數量、工廠、狀態、預計到場／安裝／實際安裝日期；點行開 Modal 看逐項明細（生產、送貨、安裝、備註等 13 欄） |
| 完工相片 | `fds2-cases-photos` | `CasePhotosPage.tsx` | 有完工相片的 `bwf_projects`，卡／列表兩種檢視，每卡最多 3 張縮圖，可開完整相簿與 Lightbox；篩選：狀態、PM、財政年度；排序：交付日期／項目編號／客戶名稱 |
| 知名客戶 | `fds2-cases-clients` | `CaseBrandsPage.tsx` | 掛了品牌標籤（`customer_tags.tag_uuid` = 固定 BRAND_TAG）的 Active 客戶：中英品牌名、Logo、相關項目數、最近 3 個項目；可勾選多個 Logo 打包下載 `知名客戶-Logo.zip`（JSZip，前端生成） |

側欄入口：`navConfig.ts`「成功案例」群組；權限：`bwf_has_role` 需 `pm`／`admin`／`uploader`／`designer`（cases 查詢）。

### 2.2 資料與權限（edge function `fetch-bwa-works`）

- 前端 `fetchCaseShowcase(kind)` → edge `supabase-functions-fetch-bwa-works`，body `{ action: "cases-orders" | "cases-photos" | "cases-brands" }`。
- PMS 資料表（唯讀，service role）：`bwf_projects`、`bwf_orders`、`bwf_products`、`factories`、`suppliers`（安裝團隊）、`staff`、`financial_years`、`customer_tags`、`customers`、`bwa_projects`、`service_types`、`project_types`、`bwa_project_project_types`。
- PMS 端再過一層 `check_permission`：訂單數據→模組 `bwf/projects`；完工相片→`completion-photos`；知名客戶→`brands`。
- 角色可見範圍（`visibleProjectIds`）：非一般 user 看全部；一般 user／senior user 只看自己負責（`project_bv.handler_id`）及（senior）同團隊的 `bwf_projects`。
- **資料不落 FDS 庫**：沿用「讀既有 PMS 契約、不複製客戶／訂單資料」的原則（見 `_shared/caseShowcase.ts` 註解）。
- 完工相片欄位 `bwf_projects.completion_photos` 若 PMS 環境未同步，回明確錯誤訊息（「請同步 PMS 的完工相片版本」）。

### 2.3 現況缺口

| # | 缺口 | 說明 |
|---|---|---|
| G-1 | 無導出 | 訂單數據、完工相片兩頁只能看，不能導出成文件給客戶；只有知名客戶可下載 Logo zip |
| G-2 | 無挑選與修改 | 不能把若干訂單／相片專案組成一份「案例集」，也不能在導出前修改對外顯示的內容 |
| G-3 | 內部欄位直接可見 | 內部頁面顯示工廠（供應商）名稱、安裝團隊、內部備註 `remarks`；這些不應出現在對外文件 |

## 3. 新增功能需求

### F-CASE-001 訂單數據頁（現況保留，不改）

維持 §2.1 所列行為。內部欄位（工廠、安裝團隊、備註）在**內部頁面**繼續顯示，不受對外脫敏影響。

### F-CASE-002 完工相片頁（現況保留，不改）

維持 §2.1 所列行為。

### F-CASE-003 知名客戶頁（現況保留，不改）

維持 §2.1 所列行為（含 Logo 打包下載）。

### F-CASE-005 客戶專區成功案例頁由發布內容驅動（已確認，2026-10-24）

- 客戶專區「成功案例」頁（`fds2-customer-cases`）由內部**發布**的精選內容驅動：讀 `case_showcase_publishes` 最新一筆 payload 渲染（工程案例卡＋服務客戶 Logo 牆）。
- 未發布任何內容時，回退顯示現有靜態 B&W 公開案例內容（`BW_PUBLIC_CASES`），頁面永不空白。
- 仍保留公司 YouTube 段落。

### F-CASE-004 案例導出（新需求）— P0

**目標（已確認）**：內部同事從訂單數據／完工相片／知名客戶**挑選**若干項目，**修改**對外顯示內容後，**導出**一份可直接交給客戶的文件。

#### 3.1 選取

- 訂單數據頁：可勾選訂單（以項目為單位，沿用現有 `project_id:project_code` 分組鍵），可配合現有搜尋與篩選（狀態／PM／工廠）。
- 完工相片頁：可勾選專案；導出相片時可再挑相片（預設全選該專案的完工相片）。
- 知名客戶頁：可勾選品牌（復用現有 Logo 勾選）。
- 跨頁可組成一份「案例集」草稿：例如「品牌 A 的 Logo + 兩個完工專案 + 對應訂單摘要」。

#### 3.2 導出前修改

- 進入導出預覽（Modal，`variant="fullscreen"` 或大尺寸）後，每個入選項目可編輯**對外顯示欄位**：項目／案例名稱、對外說明文字、日期顯示與否、相片取捨與順序。
- 修改只影響**本次導出**，不回寫 PMS（PMS 既有契約不改寫）。

#### 3.3 對外脫敏（已確認方向：對外文件不得包含內部／商業敏感資料）

| 欄位 | 內部頁 | 對外導出 |
|---|---|---|
| 項目編號／名稱 | 顯示 | 顯示（可改對外名稱） |
| 產品名稱、類型、數量 | 顯示 | 顯示 |
| 訂單狀態、生產／送貨／安裝日期 | 顯示 | 顯示（可選擇隱藏） |
| **工廠（供應商）名稱** | 顯示 | **隱藏** |
| **安裝團隊** | 顯示 | **隱藏** |
| **內部備註 `remarks`** | 顯示 | **隱藏** |
| **PM 名稱** | 顯示 | **預設隱藏，可逐項開啟** |
| 客戶顯示名稱 | 顯示 | 顯示；可逐項改代號（如「中環某金融機構」） |
| 完工相片 | 顯示 | 顯示（可挑選） |
| 品牌名稱、Logo、相關項目數 | 顯示 | 顯示 |
| 任何成本／價錢 | — | **一律不得出現**（頁面本身也無此資料，導出端不得新增） |

#### 3.4 導出格式（已確認，2026-10-24）

| 類型 | 格式 | 說明 |
|---|---|---|
| 訂單數據精選 | **Excel (.xlsx)** | 一行一訂單項目（只含對外欄位），方便客戶端再加工 |
| 完工相片／案例集 | **PDF** | 封面＋逐項目段落（相片＋對外說明）；復用前端 `@react-pdf/renderer`（報價 PDF 既有技術棧，**不引入新依賴**） |
| 一鍵導出整份案例集 | **PDF** | 已確認需要：把入選的完工相片專案＋訂單摘要＋知名客戶 Logo 牆合成一份案例集 PDF |
| 知名客戶 | 沿用現有 Logo zip；Logo 牆可併入案例集 PDF 封面「合作品牌」段落 | |

> 技術建議：前端生成（xlsx 用既有 `xlsx` 依賴、PDF 用 `@react-pdf/renderer`、zip 用既有 `jszip`），不新增 edge function；相片直接引用 `completion_photos` 的既有 URL。

#### 3.5 發布到客戶專區（已確認，2026-10-24）

- 導出預覽中可把整理好的對外內容**發布到客戶專區**「成功案例」頁（F-CASE-005）。
- FDS 新增表 `case_showcase_publishes`：只存**精選並修改後**的對外內容（`payload jsonb`：案例名稱、對外說明、相片 URL、Logo URL 等），**不複製** PMS 原始訂單／客戶資料，脫敏規則同 §3.3。
- RLS 沿用既有慣例：寫入限內部角色（`bwf_has_role`），讀取公開（anon＋authenticated）——內容本身已是對外宣傳材料。
- 不做導出審計記錄（已確認，2026-10-24）。

## 5. 驗收標準

- AC-004-1：訂單數據頁可勾選多個項目並進入導出預覽；預覽中工廠、安裝團隊、備註不出現。
- AC-004-2：可修改對外項目名稱／說明／隱藏日期，導出成品與修改一致。
- AC-004-3：完工相片可挑專案、挑相片；導出 PDF 相片與所選一致。
- AC-004-4：知名客戶 Logo 可併入導出；未勾選的品牌不出現。
- AC-004-5：一般 user 角色導出的範圍不超過其可見項目。
- AC-004-6：導出失敗（如相片 URL 失效）有明確錯誤提示，可重試。
- AC-005-1：發布後，客戶專區「成功案例」頁顯示發布內容（案例卡、Logo 牆）；再發布以最新一筆為準。
- AC-005-2：從未發布時，客戶專區顯示現有靜態 B&W 公開案例內容。

**Given / When / Then**：

| # | Given | When | Then |
|---|---|---|---|
| 1 | 同事在訂單數據頁篩選出某客戶的 5 個項目 | 勾選 3 個並導出 Excel | Excel 只含對外欄位，無工廠／備註／成本 |
| 2 | 同事選了有 20 張相片的專案 | 只留 6 張並改對外說明 | PDF 只出現 6 張與修改後說明 |
| 3 | 同事想把客戶名改為代號 | 在預覽改名 | 導出文件顯示代號，PMS 資料不變 |

## 6. 不做什麼（Out-of-Scope）

- 不在 FDS 建立訂單／客戶／相片的複製表；不做客戶端線上瀏覽案例的獨立網站。
- 不改寫 PMS 的 `bwf_orders`／`bwf_projects`／`customers` 契約與欄位。
- 內部三頁的既有查詢、篩選、分組邏輯不改（除非導出需要新增勾選 UI）。
