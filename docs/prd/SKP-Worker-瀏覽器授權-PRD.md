# FDS SKP Worker 瀏覽器授權 PRD

版本：1.0（需求草案）  
日期：2026-10-28  
狀態：待審閱；本文件不代表功能已實作、部署或通過實機驗收。

## 1. 背景與目標

目前 Windows 安裝程式要求使用者輸入 Supabase service role key，Worker 再直接認領任務、寫入心跳及上下載模型。一般使用者不應需要取得這把高權限金鑰，也不能把它放進可下載的 EXE。

改為「下載安裝程式 → 開啟瀏覽器 → 使用 FDS 帳號登入並授權這台電腦 → 自動完成連線」。首次安裝預設正式環境，使用者無需填寫 Supabase 網址或 service role key。Worker 只取得可撤銷的專用憑證，不能取得使用者的完整登入 Session 或後端管理金鑰。

### 已確認需求

- Windows 安裝程式預設正式環境。
- 安裝程式透過系統預設瀏覽器取得授權。
- 不在安裝包中內置正式環境 service role key。
- 沿用現有 SketchUp、SKP 生成、上傳檔案轉預覽及網站環境檢測流程。

### 本版提案與非目標

- 共用運算電腦由 FDS 管理員、PM 或設計師授權加入該環境的 SKP 任務池；不是任何登入用戶都能加入。
- 首期不實作個人專屬任務池、跨組織派工或跨環境代理。
- 不改建模演算法，不代替 SketchUp 授權，不承諾 Windows 登出後仍能操作 SketchUp 桌面程式。
- 授權資格已定為管理員、PM、設計師。授權期限及時限數值仍為本 PRD 的建議預設。

## 2. 現況與相容性

以下依本機程式盤點，不代表正式環境已部署相同版本。

| 現有能力 | 來源 | 沿用方式 |
|---|---|---|
| FDS 登入與 PMS SSO | `src/contexts/AuthProvider.tsx`、`src/App.tsx` | 沿用登入；登入後回到裝置授權頁 |
| 角色判定 | `bwf_has_role`、`bwf_assert_role` | 後端判定管理員、PM、設計師，不以 UI 或客戶端角色值代替 |
| Worker 安裝與加密保存 | `workers/skp-writer/installer/WorkerSetup.cs` | 沿用安裝、啟停、Windows DPAPI CurrentUser 及登入自啟 |
| SKP 任務處理 | `workers/skp-writer/worker.mjs` | 沿用 `generate_skp`、`preview_skp` |
| 任務佇列 | `processing_jobs` 及 claim／heartbeat／finish／fail RPC | 由受限後端驗證後呼叫，不向裝置開放通用 RPC |
| 環境心跳 | `fds_skp_workers`、SKP preflight RPC | 加入有效授權判定；繼續區分在線及依賴就緒 |
| 模型檔案 | 私有 `product-models` bucket、既有模型登記流程 | 沿用私有檔案與版本關聯 |

實作前核對 PMS 與 FDS 是否已有裝置授權、權限或憑證撤銷接口；有對應能力就沿用。當前尚未查詢 PMS 線上 schema，不能認定 PMS 沒有此能力。必要新增僅放在 FDS，不改寫 PMS 登入與角色契約。

## 3. 使用流程

1. 使用者從 SU 生成環境檢測視窗下載 Windows 安裝程式。
2. 安裝程式顯示「正式環境」、電腦名稱及 SketchUp 檢測結果，主要操作為「使用瀏覽器登入並授權」。測試環境放在進階設定。
3. 安裝程式建立短效配對請求，顯示配對碼並開啟受信任的 FDS HTTPS 授權頁；無法自動開啟時可複製授權網址及配對碼。
4. 瀏覽器沿用 FDS 登入。未登入先登入，完成後返回同一配對請求，過期則要求重新開始。
5. 授權頁顯示環境、電腦名稱、配對碼、申請時間及允許的任務範圍；提醒管理員核對安裝程式的配對碼。
6. 管理員、PM 或設計師點擊「授權這台電腦」。登入本身不代表同意授權；拒絕、關閉或過期不產生有效裝置權限。
7. 安裝程式經原本配對請求領取 Worker 專用憑證，以 Windows DPAPI 保存，完成安裝並啟動。
8. 顯示「已授權／已連線／環境就緒」的分別結果。若 SketchUp 尚未登入或選模板，提供具體操作提示。
9. 回到 FDS 重新檢測，實際生成一個 SKP 並在 SketchUp 開啟驗證。

瀏覽器可以在完成授權後關閉；Windows 帳號仍需保持登入，供 SketchUp 執行。

## 4. 授權與權限需求

### FR-01 裝置配對

- 建議使用裝置碼配對及安裝程式輪詢結果；不依賴讀取瀏覽器 Cookie、複製 Session 或開放本機任意回呼端點。
- 配對請求綁定環境、安裝實例及密碼學隨機秘密；電腦名稱僅供辨識，不能作為認證依據。
- 建議有效期 10 分鐘、輪詢間隔至少 5 秒。服務端限制建立、查碼、批准及輪詢頻率，過快回傳退避要求。
- 公開配對碼與領取憑證用的裝置秘密分離；瀏覽器 URL 不含裝置秘密、Worker token 或使用者登入 token。
- 批准及領取必須原子化，防止重複批准、跨環境領取與重放。領取回應遺失時提供有界、綁定原裝置證明的恢復流程；不能重放建立額外授權。
- 切換環境或重新發起配對時取消舊請求，不得把舊結果寫入新環境設定。

### FR-02 授權資格

- 只允許後端確認的 FDS 管理員、PM 或設計師批准共用 Worker，並可查看與撤銷已加入的電腦。其他帳號顯示「請由管理員、PM 或設計師授權」，不能因使用者可以生成模型而自動允許其接收全站模型任務。
- 授權說明明確指出：這台電腦可能取得該環境派發任務的產品資料及模型檔，須是公司信任的電腦。
- 後端重新驗證登入、環境、角色、請求有效期及狀態；禁止只有前端權限檢查。
- 瀏覽器登出不撤銷已批准裝置；批准人停用或不再是管理員、PM、設計師時，其批准的裝置暫停，需另一位仍有資格的同事重新批准。

### FR-03 Worker 專用憑證

- 每個安裝實例使用獨立裝置 ID 與可撤銷憑證，不以電腦名稱作唯一識別。
- 建議短效 access token 有效期 15 分鐘、可輪換的 refresh credential 最長 30 天；到期重新走瀏覽器授權。
- 憑證綁定環境、裝置及有限用途；不能充當 Supabase service role、使用者 Session 或通用資料庫憑證。
- 長效秘密僅在裝置以 DPAPI CurrentUser 加密保存；服務端保存雜湊或等效驗證資料。不得寫入 Git、安裝包、網址、分析事件、錯誤回應或日誌。
- 更新憑證採原子寫入；並發刷新及網絡中斷不得使有效設定遭半寫入破壞。偵測 refresh 重放時撤銷該憑證鏈並要求重新授權。
- 複製設定到其他 Windows 帳號或電腦不能解密；重裝保留有效設定，解除連線則刪除本機憑證。

### FR-04 受限的任務代理

- service role 僅保留在後端。Worker 透過明確操作接口進行 readiness、claim、任務心跳、輸入下載、輸出上傳、完成及失敗回報。
- 服務端只允許 `generate_skp`、`preview_skp`；禁止任意 table、RPC、bucket、URL 或 SQL 透傳。
- 每次認領簽發綁定裝置、job ID 及該次嘗試的 lease。後續操作同時驗證裝置授權、任務狀態、lease 與有效期。
- 同一任務重派後，舊 Worker 不可覆寫新結果。完成回報要冪等；取消、失效或已完成任務拒絕新的結果寫入。
- Worker 只能取得已認領任務所需的參數及指定輸入檔；不得列舉所有產品、任務或模型。
- 檔案傳輸使用後端受限代理或短效簽名 URL；路徑由服務端產生並與任務綁定，限制格式、大小及上傳權限。完成時驗證物件、大小、雜湊及任務關聯。
- 撤銷後立即拒絕新 API 操作；已簽發 URL 的剩餘有效期須有上限，建議不超過 5 分鐘。撤銷後即使檔案已上傳，也不得登記為成功結果。
- 沿用現有重試及並發規則，不能透過安裝多台 Worker 繞過佇列限制。

### FR-05 管理與撤銷

- 在 FDS 系統設定提供 Worker 清單：裝置名稱、ID、環境、版本、授權者、批准及到期時間、最後心跳、依賴狀態和目前任務。
- 管理員、PM 或設計師可撤銷裝置；安裝程式可解除本機連線及重新授權。
- 撤銷後停止領取工作，網站即使仍有 90 秒內心跳也不得把該裝置視為可用。
- 執行中的任務在下一次檢查發現撤銷後安全停止，禁止提交；依既有 lease 超時與重試政策恢復，不無限制重試。
- 撤銷操作、重新授權及角色變更留存審計紀錄，不含憑證內容。

## 5. 狀態與介面

| 狀態 | 使用者看到的內容 | 可用操作 |
|---|---|---|
| 未授權 | 尚未連接 FDS | 瀏覽器登入並授權 |
| 等待批准 | 配對碼、環境、剩餘時間 | 複製網址、取消 |
| 拒絕／過期 | 明確原因 | 重新授權 |
| 已授權但離線 | 已保存設定，連線失敗 | 重試、查看已遮蔽秘密的記錄 |
| 已連線但缺依賴 | 具體缺少的 SketchUp／腳本／SDK 元件 | 安裝指引、重新檢測 |
| 就緒 | 可認領 SKP 任務 | 啟停、檢查狀態 |
| 授權被撤銷／到期 | 已停止領取任務 | 重新授權 |

「授權成功」「收到有效心跳」「具備執行依賴」「真實 SKP 生成成功」必須分別呈現。不能用檔案存在或連線成功宣稱 SketchUp 授權及實際寫檔已通過。

網站使用 `src/components/ui` 的共用元件；授權頁顯示清楚的正式／測試環境，不展示內部金鑰欄位。保留 SU 環境檢測視窗的 Worker 下載入口。

## 6. 資料與接口邊界

新增概念僅在現有 PMS／FDS 無等效能力時引入；以下是需求資料，不是已確定的 table 或 slug 名稱。

| 概念 | 必要資料 |
|---|---|
| 配對請求 | 環境、裝置證明摘要、顯示碼、建立／到期時間、狀態、批准者、領取狀態 |
| 裝置授權 | 不透明裝置 ID、環境、名稱、批准者、狀態、有效期、撤銷原因、憑證版本 |
| 任務 lease | job ID、裝置 ID、嘗試次數或不可重用 lease ID、有效期 |
| 審計事件 | 授權／拒絕／輪換／撤銷／認領／完成／失敗、時間、主體、關聯 ID、結果 |

裝置憑證資料預設不向一般 authenticated 使用者開放；管理員頁使用有權限檢查的接口，不直接查秘密資料。沿用 `processing_jobs`、模型表及 bucket，不建立平行任務系統。部署 Edge Function 前核對前端與 Worker 實際使用的 slug。

## 7. 驗收條件

| 編號 | 驗收場景 | 通過條件 |
|---|---|---|
| AC-01 | 乾淨 Windows 電腦安裝 | 預設正式環境；全流程不要求或下發 service role key |
| AC-02 | 未登入／已有登入 | 均可到正確授權頁，登入不會自動批准 |
| AC-03 | 非管理員登入 | 後端拒絕批准，直接呼叫接口也不能繞過 |
| AC-04 | 正式與測試切換 | 請求、憑證、任務及檔案不能跨環境使用 |
| AC-05 | 配對過期、拒絕、重放、暴力查碼 | 不產生額外有效授權，有限速及可理解的錯誤 |
| AC-06 | 合法 Worker 認領任務 | 只能操作自己的有效 lease 及所需輸入輸出 |
| AC-07 | 竄改 job ID、路徑、類型、裝置 ID | 服務端拒絕；其他產品與任務不受影響 |
| AC-08 | 任務重派或完成請求重送 | 舊 lease 不可覆寫；同一次完成不產生重複版本 |
| AC-09 | 管理員撤銷或權限被移除 | 停止領取及提交；網站不再視為可用 Worker |
| AC-10 | 重啟、更新、失聯、刷新回應遺失 | 有效設定可恢復；不洩漏憑證、不無限重試 |
| AC-11 | 真實生成與預覽 | SKP 可在 SketchUp 開啟編輯；上傳 SKP 的 GLB 預覽可用 |
| AC-12 | 安裝包與前端產物檢查 | 無 service role、使用者 Session、裝置秘密或正式環境私密設定 |
| AC-13 | 日誌與錯誤處理 | 可查詢環境、裝置和任務關聯，所有秘密已遮蔽 |

安全負向測試、模擬端點及建置成功不能代替 AC-01、AC-11 的實機驗收。

## 8. 發佈與遷移

1. 核對 PMS/FDS 現有契約，確定角色政策、期限及接口；補上裝置授權、lease 與撤銷測試。
2. 在測試環境部署資料結構、受限代理及授權頁，完成權限與跨環境測試。
3. 更新 Worker 與安裝程式，移除一般安裝流程的 service role 輸入；在乾淨 Windows 電腦走完整瀏覽器授權及真實建模驗收。
4. 正式環境先部署後端及前端，再替換下載安裝包；記錄版本、SHA256、目標專案、實際 function slug 及部署後讀回結果。
5. 舊 Worker 在沒有執行中任務時轉換；成功取得新授權後刪除舊 DPAPI 設定中的 service role，不能把舊金鑰遷移進新憑證格式。
6. 盤點其他服務後輪換曾公開貼出的正式環境高權限金鑰；不把金鑰內容寫入本文件。舊 Worker 的停用時間及回復方式需明確記錄。
7. 回退時停用新認領，保留既有模型及任務記錄；不得以重新公開管理金鑰作為回退方案。

## 9. 實作前需定案

- 是否接受首期僅管理員批准、裝置加入共用 SKP 任務池？若需個人 Worker，必須另定任務歸屬及資料授權模型。
- 是否採用本文件建議的配對、token、簽名 URL 有效期及撤銷規則？
- 正式及測試的受信任授權頁網址、安裝包簽章責任人、舊 Worker 遷移期限。
