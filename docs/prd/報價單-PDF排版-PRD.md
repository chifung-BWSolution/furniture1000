# PRD｜報價單 PDF 排版優化

**版本：** V1.1
**修訂依據：** 參考報價單 BWF-SH26-114 R7（見「附錄 A：參考圖」）
**優先級：** P0
**適用格式：** A4 直向 PDF
**開發目標：** 支援任意數量 Item、自適應圖片排版及智能分頁的正式傢俱報價單

---

## 0. 本版修訂說明（V1.0 → V1.1）

本版按參考圖修訂，V1.0 的設計原則不變，以下為實質差異：

| # | V1.0 | V1.1（依參考圖） |
|---|---|---|
| 1 | Item 表格 8 欄，說明與規格合併 | **9 欄**：序號／產品及說明／規格(mm)／材質及明細／圖片／數量／單位／單價／總額 |
| 2 | 備註獨立成欄（9%） | 備註**併入「材質及明細」**尾段；備註內嵌圖片移到「圖片」欄 |
| 3 | 圖片欄 20%（36–40mm） | 圖片欄 **18%（約 34mm）**，圖片以**單欄垂直堆疊**為主 |
| 4 | 頁首只有「第一頁完整／續頁簡化」 | 明確分成**三種頁型**：首頁／續頁／末頁，並給出線框 |
| 5 | 圖片排版以「候選方案評分」描述 | 改為參考圖的 **4 個標準版式（示例 1–4）**，評分只作補充 |
| 6 | 報價單圖片（尾段）只寫「排在總價之後」 | 明確**兩組圖片的合併與分工**：Item 圖片欄 + 尾段「圖片排版」區塊，共用同一套量測與分頁 |
| 7 | 頁碼格式 `Page X / Y` | 同左，位置固定**右下角**；首頁左下角改為公司資料 |

> 本次只調整 PDF **排版與呈現**，不改報價金額計算、不改資料庫結構、不改業務條款文字。

## 一、專案背景

### 1.1 現有問題

1. 圖片欄過窄（約 63pt／22mm），產品圖看不清。
2. 圖片橫向、直向比例不一，固定高度圖框會把圖縮得很小。
3. 單個 Item 可能有 2–3 張圖片（產品圖、參考圖、備註圖），目前只能上下硬塞。
4. 材質說明長度不固定，容易造成版面失衡。
5. Item 數量不固定（1、5、10、30 個都可能）。
6. 無法預先知道 PDF 頁數，必須依內容分頁。
7. 不能為了塞進一頁而縮小文字或裁切圖片。
8. 設計圖不是必填，不能假設每個 Item 都有。

### 1.2 設計目標

- 保留原有報價單的表格結構（序號／說明／規格／材質／圖片／數量／單位／單價／總額）。
- A4 直向列印，正式、簡潔、可商業報價。
- 支援任意數量 Item，頁數由內容決定。
- 每個 Item 支援 1–3 張（必要時更多）圖片的自適應排版，橫直混合不裁切。
- 文字、圖片、金額均不可截斷。
- 首頁／續頁／末頁三種頁型表現一致、可預期。

### 1.3 非目標

- 不改報價單編輯系統的資料流程。
- 不改成本、售價、折扣、安裝費的計算規則。
- 不改資料庫 schema。
- 不 AI 生成產品圖、不強制使用者重傳圖片。
- 不強制每頁固定 Item 數。

## 二、版面規格與頁面結構

### 2.1 文件規格

| 項目 | 規格 |
|---|---|
| 紙張 | A4（210 × 297mm） |
| 方向 | Portrait（唯一預設） |
| 頁邊距 | 左右 12mm、上 12mm、下 14mm（含頁尾） |
| 主要字級 | 8–9pt |
| 表格／價格字級 | 7.5–8pt |
| Item 名稱 | 8.5–9pt，粗體 |
| 表格線 | 0.5pt，`#9aa3ab`；外框同色 |
| 背景 | 白色；表頭淡灰 `#f2f4f6`；區隔列 `#f5f7f9` |
| 強調色 | 深灰（主文字 `#1a1a1a`）／淡藍灰（表頭、區隔） |
| 輸出 | 文字可選取、可搜尋、可列印 |
| 總頁數 | 不限制 |

字級為建議值，實際以 100% 列印測試確認清晰度；調整字級時必須同步調整分頁量測，不得只改字級。

### 2.2 三種頁型

參考圖的 PDF 由三種頁型組成，同一份文件可重複出現：

```
【首頁】
┌───────────────────────────────────────────────────────┐
│ BW  FURNITURE                 報價單號: BWF-SH26-114 R7│
│                               報價日期: 2026-10-23     │
│                               修訂日期: 2026-10-23     │
│                               有效期: 30 天           │
│                    傢俱報價單 / QUOTATION              │
│ 公司名稱: …………………      公司: ………………………………………  │
│ 客戶名稱: …………………      地址: ………………………………………  │
│ 客戶電話: …………………      電話: ………………………………………  │
├───┬──────────┬────────┬────────────┬──────┬──┬──┬────┬────┤
│ # │產品及說明 │規格(mm)│材質及明細  │圖片  │數│單│單價│總額│
├───┼──────────┼────────┼────────────┼──────┼──┼──┼────┼────┤
│ 1 │ …        │ …      │ …          │ 圖   │6 │set│4980│29880│
│ 2 │ …        │ …      │ …          │ 圖   │2 │set│4450│ 8900│
├───┴──────────┴────────┴────────────┴──────┴──┴──┴────┴────┤
│ 傢俱安裝費用 …            FREE                            │
├──────────────────────────────────────────────────────────┤
│                              總金額 TOTAL (HKD) HK$38,780 │
├──────────────────────────────────────────────────────────┤
│ YOUR COMPANY LIMITED …                        （左下角）  │
└──────────────────────────────────────────────────────────┘
```

```
【續頁】（第 2 頁起，只要有 Item 就重複表頭）
┌───────────────────────────────────────────────────────┐
│ BW  FURNITURE                 報價單號: BWF-SH26-114 R7│
├───┬──────────┬────────┬────────────┬──────┬──┬──┬────┬────┤
│ # │產品及說明 │規格(mm)│材質及明細  │圖片  │數│單│單價│總額│  ← 表頭重複
├───┼──────────┼────────┼────────────┼──────┼──┼──┼────┼────┤
│ 3 │ …        │ …      │ …          │ 圖   │4 │set│3900│15300│
│ … │          │        │            │      │  │  │    │     │
│                                                    Page 2 / 4│
└───────────────────────────────────────────────────────┘
```

```
【末頁】（Item 與金額之後）
┌───────────────────────────────────────────────────────┐
│ BW  FURNITURE                 報價單號: BWF-SH26-114 R7│
│ 費用統計                                               │
│ 交付安排                                               │
│ 條款及細則（可自然跨頁）                               │
│ 客戶確認 / 簽署                                        │
│                                                    Page 4 / 4│
└───────────────────────────────────────────────────────┘
```

規則：

1. **首頁**一定要有完整公司／客戶資料；即使第一個 Item 很矮也不提早分頁。
2. **續頁**頁首簡化為「Logo + 報價單號」一行，下方緊接重複表頭。
3. **末頁**沒有 Item 時不印表頭。
4. 同一頁可以同時包含「Item 尾段 + 費用統計」，不必為了換區塊而強制分頁。

### 2.3 頁首

**首頁（完整）**

- 左上：公司 Logo（約 130 × 32pt，等比）。
- 右上：報價單號、報價日期、修訂日期（如啟用）、最新修改日期（如啟用）、有效期（如提供），右對齊、標籤灰字。
- 中央標題：`傢俱報價單`；英文版 `Furniture Quotation`（參考圖另加一行 QUOTATION，僅在中文版可選）。
- 左欄：公司名稱、客戶名稱、客戶電話、客戶電郵、報價單號、日期、修訂日期、項目負責人。
- 右欄：公司、地址、電話、電郵、網站。
- 有 QR Code 時放在左欄資料下方（64pt），說明文字最多兩行。

**續頁（簡化）**

- 左：Logo（78 × 20pt）。
- 右：`報價單號: BWF-SH26-114 R7`。
- 下方 0.5pt 分隔線，高度固定 26pt。
- 續頁**不重複**客戶資料與 QR。

### 2.4 頁尾

- **所有頁面**右下角：`Page X / Y`，7pt 灰字，Y 為實際總頁數（含封面／封底，如有）。
- **首頁**左下角：公司名稱、地址、電話｜電郵｜網址（7pt，最多兩行）；續頁不重複。
- 頁尾固定在頁面底部保留區內，正文不得侵入；頁尾高度不計入可用排版高度。

### 2.5 文件區塊順序

| 區塊 | 內容 | 位置 |
|---|---|---|
| A | 報價單頁首 | 第 1 頁 |
| B | Item 詳情列表 | 第 1 頁起，可連續多頁 |
| C | 安裝費列 + 費用統計 + 報價總額 | Item 之後，不可拆頁 |
| D | 報價單圖片（尾段圖片排版） | 總額之後、交付安排之前 |
| E | 交付安排（訂單確認及交付細節） | 圖片之後 |
| F | 條款及細則 | 交付安排之後，可跨頁 |
| G | 客戶確認／簽署 | 文件最後 |

> V1.0 的 A–F 區塊內容全部保留，本版只把「報價單圖片」明確插入 C 與 E 之間。

## 三、Item 表格（9 欄）

### 3.1 欄位與寬度

| 欄位 | 寬度 | 說明 |
|---|---:|---|
| 序號 | 3.5% | 產品流水號，不含區隔標題列 |
| 產品及說明 | 15.5% | 產品名稱（粗體）＋描述 |
| 規格 (mm) | 10% | W\*D\*H 或 DIA\*H；下方顯示顏色 |
| 材質及明細 | 27% | 富文本清單；末尾可帶備註 |
| 圖片 | 18% | 1–3 張（可更多）自適應排版 |
| 數量 | 4% | 右對齊／置中 |
| 單位 | 4% | set／pcs… |
| 單價 (HKD) | 8% | 千位分隔 |
| 總額 (HKD) | 10% | 粗體 |

- 欄寬是版面參數，集中在一處設定，不得散落在各元件；調整後必須重新驗證金額不被截斷。
- 英文版可把「產品及說明」加寬至 18%、材質減至 24.5%，其餘不變。
- 合計必須為 100%。

### 3.2 各欄內容規則

**序號**
- 置中、7.5pt；區隔標題列不編號（沿用現有 `productSerialAt()` 邏輯）。
- 超長 Item 的續段顯示空白，說明欄標「（續）」。

**產品及說明**
- 第一行為產品名稱，粗體 8.5–9pt，靠左，可折行。
- 第二行起為描述（若有），8pt，行高 1.45。
- 不可為了對齊而壓縮成一行。

**規格 (mm)**
- 先顯示尺寸別標籤（`W*D*H` 或 `DIA * H`，6.5pt 灰字），再顯示數值。
- 數值只在 `*` 之間換行，單一數字不可被切斷。
- 尺寸缺失時整行隱藏，不顯示空標籤。
- 顏色：以「色點 + 顏色名稱」顯示（參考圖樣式）；多色以逗號分隔並逐一顯示色點。
- 規格與顏色皆無時，本欄留空但不顯示「—」等假資料。

**材質及明細**
- 保留段落與清單格式（`•` 項目符號），富文本的粗體、底線、顏色沿用。
- 行高 1.45、8pt；長段落自動折行，不截斷。
- 備註（若有）接在材質之後，以小標「備註」＋ 7.5pt 文字呈現，不另設欄。

**圖片**
- 見第四章；無圖片時不顯示任何佔位框或「未提供圖片」文字。

**數量／單位**
- 置中；數量最多 4 位 + 千位分隔；單位沿用資料原值。

**單價／總額**
- 右對齊或置中（同欄一致）；`HK$` + 千位分隔。
- 金額欄放不下時先縮字級（最小 6pt），仍放不下才折行；**不可截斷**。
- 可選產品（`isOptional`）的總額欄顯示「可選」，不計入合計。

### 3.3 列高與對齊

```
Item 列高 =
  max(產品及說明高度, 規格高度, 材質高度, 圖片組高度, 價格格高度)
  + 上下內距
```

- 內距：上下各 5pt、左右各 2–3pt。
- 各欄頂部對齊；數量／單位／單價／總額垂直居中。
- 相鄰 Item 以 0.5pt 細實線分隔；不加大面積背景色（區隔標題列除外）。
- 表格左右外框與底部收邊在每頁都要閉合（頁尾最後一列補底線）。

### 3.4 特殊列

| 列型 | 呈現 |
|---|---|
| 區隔標題（一、開放區） | 整列合併，`#f5f7f9` 底、9pt 粗體、高 22pt |
| 分區小計 | 整列合併，左標題右金額、8pt 粗體、高 20pt；依 `zoneSubtotalPlacement` 設定顯示 |
| 自訂條款列（`isCustomTerm`） | 說明跨「產品及說明＋規格」兩欄，材質跨「材質及明細」，金額照常 |
| 安裝費列 | 左說明（標題＋副標），中條件文字，右單價／總額（FREE 或金額），高 ≥ 28pt |
| 於 PDF 隱藏（`hideInPdf`） | 不輸出、不佔高度、不參與合計 |

## 四、圖片排版（Item 圖片 + 尾段報價單圖片）

### 4.1 兩組圖片、一套管線

報價單有兩組圖片，**排版引擎、量測方式、分頁規則必須共用**：

| 組別 | 來源 | 位置 | 版式 |
|---|---|---|---|
| **A. Item 圖片** | 編輯器每個 Item 的產品圖、參考圖、備註內嵌圖、設計圖 | Item 表格的「圖片」欄 | 第 4.3 節四種標準版式（自動） |
| **B. 尾段報價單圖片** | 「報價單圖片」圖片庫選擇＋排版（L01–L21 模板、3 欄網格） | 總額之後、交付安排之前 | 使用者選定模板（沿用現有排版） |

合併規則：

1. Item 圖片按 **產品圖 → 參考圖 → 備註圖 → 設計圖** 順序合併，URL 去重。
2. 同一 Item 的圖片一律進同一個圖片欄，不得一張進圖片欄、一張留在備註欄。
3. 兩組圖片都**不得裁切**（`object-fit: contain`），比例不符時留白而非裁切。
4. 兩組圖片都是分頁的「原子區塊」：不可被頁面切開；單張圖永遠完整。
5. 資料接口建議：

```ts
interface QuotationPdfItem {
  // …原有欄位
  images?: Array<{
    url: string;
    kind?: 'product' | 'reference' | 'remarks' | 'drawing' | 'other';
  }>;
}
```

> 舊資料沒有 `images` 時，由 PDF 從 `image` / `referenceImage` / `remarks` 自動組合，不需要遷移資料。

### 4.2 圖片欄尺寸

| 參數 | 值 |
|---|---|
| 欄寬 | 18%（A4 內容寬約 538pt → 約 97pt／34mm） |
| 可用寬度 | 欄寬 − 左右內距 4pt |
| 單張最大高度 | 45mm |
| 圖片組最大高度 | 168pt（約 59mm） |
| 圖片間距 | 1.5–2mm |
| 圖片裁切 | 禁止 |
| 對齊 | 圖片組在欄內水平置中 |

### 4.3 四種標準版式（以參考圖為準）

**示例 1：2 張橫向圖片 → 上下堆疊**

```
┌──────────┐
│  ▁▁▁▁▁▁  │  ← 橫圖，滿欄寬
│  ▔▔▔▔▔▔  │
│  ▁▁▁▁▁▁  │  ← 橫圖，滿欄寬
│  ▔▔▔▔▔▔  │
└──────────┘
```
- 兩張同寬，各自保持原比例；總高超過上限時整組等比縮小（不裁切）。

**示例 2：2 張直向圖片 → 左右並排**

```
┌──────────┐
│ ┌──┐┌──┐│  ← 兩張直圖，各佔半欄寬
│ │  ││  ││
│ │  ││  ││
│ └──┘└──┘│
└──────────┘
```
- 避免直圖上下堆疊造成圖片欄過高。

**示例 3：1 張橫向 + 1 張直向 → 上下堆疊（橫圖在上）**

```
┌──────────┐
│  ▁▁▁▁▁▁  │  ← 橫圖
│  ▔▔▔▔▔▔  │
│   ┌──┐   │  ← 直圖，置中
│   │  │   │
│   └──┘   │
└──────────┘
```
- 若左右並排會讓任一張寬度小於欄寬 42%（約 41pt），改用上下堆疊。

**示例 4：3 張混合圖片 → 主圖 + 2 小圖**

```
┌──────────┐
│  ▁▁▁▁▁▁  │  ← 主圖（滿寬）
│  ▔▔▔▔▔▔  │
│ ┌──┐┌──┐ │  ← 2 張小圖並排
│ └──┘└──┘ │
└──────────┘
```
- 主圖優先選比例最寬（或尺寸最大）的一張；不強制第一張當主圖。
- 三張同為直向時，可改用三欄並排（前提是每張寬度 ≥ 欄寬 42%）。

### 4.4 版式決策表

| 圖片數量／比例 | 採用版式 | 備註 |
|---|---|---|
| 0 張 | 不顯示 | 不顯示佔位框、不顯示提示文字 |
| 1 張 | 單張 | 滿欄寬；直圖超過 45mm 時按比例收窄並置中 |
| 2 張，皆橫向 | 上下堆疊 | 示例 1 |
| 2 張，皆直向或正方形 | 左右並排 | 示例 2 |
| 2 張，一橫一直 | 上下堆疊 | 示例 3；並排會過窄時同樣用堆疊 |
| 3 張，混合 | 主圖 + 2 小圖 | 示例 4 |
| 3 張，皆直向 | 三欄或主圖 + 2 小圖 | 取「每張寬度 ≥ 42% 欄寬」中高度較小者 |
| 3 張，皆橫向 | 主圖 + 2 小圖 | 三欄會使每張僅約 12mm，不可用 |
| 4 張以上 | 每 3 張一組，垂直堆疊 | 組間距 2–3mm；仍超高度上限則整組縮小 |

比例分類：

```
ratio = 原始寬 / 原始高度
橫向    ratio > 1.1
正方形  0.9 ≤ ratio ≤ 1.1
直向    ratio < 0.9
```

門檻值、欄寬 42% 下限、45mm 上限、間距全部集中為可調參數，不得寫死在多個元件。

### 4.5 設計圖（選填）

- 設計圖與其他圖片使用同一套自適應版式，不預留專用欄位。
- 有設計圖時允許它佔用較大寬度（可作為主圖），確保圖中標註可辨識。
- 沒有設計圖時直接顯示產品圖，不顯示空白圖框，也不顯示「未提供設計圖」。

### 4.6 尾段「報價單圖片」

- 沿用現有圖片庫排版（L01–L21、3 欄網格、說明文字）。
- 位置固定在**總額之後、交付安排之前**。
- 每個排版區塊為不可分割原子塊；若單塊高度超過一頁可用高度，整塊等比縮小至可用高度內（不裁切、不拆頁）。
- 與 Item 圖片一樣，圖片比例以原始尺寸計算，`contain` 顯示。

## 五、智能分頁

### 5.1 原則（優先順序）

1. 不截斷文字。
2. 不截斷、不裁切圖片。
3. 保持 Item 內容關聯（標題、金額不分離）。
4. 減少不必要空白。
5. 避免只剩少量內容的孤立頁。

不得為減少頁數而縮小字級。

### 5.2 每頁可用高度

```
首頁可用高度 = 297mm − 上邊距 − 下邊距（含頁尾） − 首頁頁首高度 − 表頭高度
續頁可用高度 = 297mm − 上邊距 − 下邊距（含頁尾） − 續頁頁首 26pt − 表頭高度
末頁可用高度 = 續頁可用高度（無表格時可加回表頭高度）
```

- 頁首、表頭高度由量測結果決定並在整份文件固定，不逐頁浮動。
- 浮點誤差保留 4pt 安全邊際。

### 5.3 Item 分頁

| 情況 | 處理 |
|---|---|
| A. 當前頁空間足夠 | 整個 Item 放當前頁 |
| B. 空間不足，但 Item 可放完整一頁 | 整個 Item 移到下一頁（不留半個 Item） |
| C. Item 本身超過一頁 | 允許跨頁，見下 |
| D. 圖片組放不進剩餘空間 | 先把整組移到下一頁；若整組超過一頁，才在不同圖片行之間分頁，單張圖不可切開 |

情況 C 的續頁規則：

- 第一段保留「產品及說明 + 規格 + 價格」，材質與圖片按行續排。
- 續段說明欄顯示「（續）」，序號留空，**不重複數量、單價、總額**。
- 材質按段落／行延續，不切斷單行文字。
- 每段都重新印表頭。

### 5.4 表頭

- 跨頁重複：序號、產品及說明、規格、材質及明細、圖片、數量、單位、單價、總額。
- 高度由統一表頭樣式決定（≥ 24pt），同一份文件所有頁一致。
- 首頁表頭緊接客戶資料下方；續頁表頭緊接簡化頁首下方。
- 只有條款／簽署、不含 Item 的頁面不印表頭。

### 5.5 金額區

- 安裝費列接在 Item 表格最後，屬表格的一部分（保留外框）。
- 費用統計（折扣、分區總表、總金額、CNY 總額）為**不可拆分的原子區塊**。
- 當前頁放不下 → 整塊移到下一頁；不得只有標籤留在頁尾、金額掉到下一頁。
- 不改原有折扣與金額計算邏輯。

### 5.6 末頁

- 順序：費用統計 → 報價單圖片 → 交付安排 → 條款 → 簽署。
- 條款允許自然跨頁，但：
  - 小節標題與首段必須同頁（標題不可孤立頁尾）。
  - 有序清單編號連續。
  - 不切斷單行文字。
  - 段落間距一致。
- 簽署區高度固定（約 92pt），盡量整塊同頁；若剩餘空間不足則整塊移到下一頁。
- 不出現只有頁尾的空白頁。

### 5.7 頁碼

- 每頁右下角 `Page X / Y`，Y 為排版完成後的實際頁數。
- 頁碼不得依賴預估頁數；若封面／封底存在，一併計入。
- 頁碼區域與正文之間保留 4pt 間距。

## 六、頁面高度計算

### 6.1 核心思路

不使用固定 Item 高度。每個 Item 的高度由實際內容決定：

```
Item 高度 =
  max(說明高度, 規格高度, 材質高度, 圖片組高度, 價格格高度)
  + 上下內距
```

### 6.2 量測流程

1. 讀取報價單資料。
2. 正規化 Item（序號、區隔標題、可選、隱藏）。
3. 預載所有圖片，取得原始寬高（失敗則視為正方形）。
4. 依比例選出圖片版式與尺寸。
5. 用**與 PDF 相同的字體**量測文字，先換行成「行」。
6. 逐行累加高度（行高固定）。
7. 計算每頁可用高度（首頁／續頁不同）。
8. 依區塊高度分頁。
9. 產生 PDF。
10. 檢查是否有溢出（區塊總高 > 該頁可用高度即視為異常）。

> 關鍵：先把文字換行成固定行高的「行」，再按行數算高度。渲染時直接把行印出，
> 不再讓 PDF 引擎自動換行，這樣量測高度與實際高度一致。

### 6.3 分頁演算法

```ts
type PdfBlock = {
  key: string;
  heightPt: number;          // 已量測
  keepWithNext?: boolean;    // 標題 + 首段綁定
  table?: boolean;           // 屬 Item 表格（決定是否印表頭）
};

for (const block of blocks) {
  if (block.height <= remainingCapacity) {
    addToCurrentPage(block);
    continue;
  }
  if (block.height <= fullPageCapacity) {
    createNewPage();
    addToCurrentPage(block);
    continue;
  }
  // 超長 Item：先在 buildItemBlocks 內切成多段，再逐段分頁
  for (const segment of splitOversizedItem(block)) {
    placeSegmentWithPagination(segment);
  }
}
```

實作必須處理：

- 首頁／續頁可用高度不同。
- 表頭、頁首、頁尾高度。
- 圖片組不可任意拆分。
- 浮點誤差（保留安全邊際）。
- 最後一頁填充率過低時，可把前一頁尾部區塊搬到最後一頁（不得拆散標題與首段）。

### 6.4 與 CSS 的關係

`break-inside: avoid` 不足以處理超長 Item，只能作輔助。實際分頁由量測與分頁模組決定；
若仍使用 CSS 分頁（HTML→PDF 方案），必須額外提供「量測 → 分頁」的程式邏輯。

- 紙張尺寸固定 A4，列印時不縮放（100%）。

## 八、異常情況

| 情況 | 處理 |
|---|---|
| Item 沒有圖片 | 不顯示圖片內容，該欄留空，其餘欄位正常延伸 |

| Item 超過一頁 | 啟用跨頁延續，價格只在第一段 |

| 條款很長 | 自然跨頁，標題不孤立 |
| 沒有圖片庫排版 | 退回 3 欄網格（`quotePhotos`） |
| PDF 生成失敗 | 回傳可追蹤錯誤，不輸出不完整文件 |

## 十一、AI 開發執行要求

1. 先分析現有 PDF 生成流程、模板與資料結構，不要重寫報價業務邏輯。
2. 沿用現有 Item、金額、條款、圖片庫資料，不新增重複接口。
3. 圖片排版與分頁計算拆成獨立模組，可單獨測試。
4. 以 A4 直向為唯一預設；紙張、邊距、欄寬、字級集中在參數檔。
5. 不可假設報價單只有 2 個 Item、只有 1 頁、圖片全是橫向、每個 Item 都有設計圖。
6. 不得用固定 Item 高度壓縮文字；不得為塞進一頁而截斷文字、圖片或金額。
7. 完成後輸出測試 PDF，至少涵蓋：2／5／10 個 Item、4 種圖片版式、無圖片、超長材質、無設計圖。
8. 逐頁檢查圖片、文字、金額、頁碼、表頭與分頁。
9. 保持與現有報價單視覺風格及業務流程相容。

## 十二、最終驗收目標

**視覺**
- 正式、簡潔、適合商業報價。
- 圖片比原模板更容易辨識，多張圖片排列合理。
- 不同比例圖片混排時版面整齊。
- 不過度留白、不密集擁擠。

**功能**
- 任意數量 Item 正常輸出。
- 自動分頁，首頁／續頁／末頁結構正確。
- 圖片、文字、金額、條款完整。
- 頁碼與表頭正確。

**工程**
- 不影響現有報價計算。
- 不強制修改資料庫。
- 模板易維護。
- 圖片版式與分頁演算法可獨立測試。
- 可穩定生成多頁正式 PDF。

> 最終原則：以內容完整、列印清晰、排版合理為優先，不限制 Item 數量與 PDF 頁數。
