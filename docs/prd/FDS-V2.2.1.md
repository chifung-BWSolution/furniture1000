## 1. 這次要改什麼

現有簡報精靈是四步：填需求、確認五段大綱、選產品、呼叫 Canva。產品頁是「每一件產品自己一頁」，選完就生成。會議要求改成：先有空間分區，再選產品，然後把即將生成的大綱詳細內容列出來並可編輯，最後才呼叫 Canva。Canva 負責排版，業務資料留在 FDS。

正式報價 PDF 繼續做商務報價。簡報做方案說明和公司實力。兩份文件分開出，可以一起交給客戶。本階段不把整份簡報塞進報價 PDF，也不做完整的 AI 室內效果圖流程。

### 1.1 相對 V2.2 的差異

| 議題 | V2.2 | V2.2.1 |
|---|---|---|
| 簡報步驟 | 選項目後載入模板、分區、產品、案例，再預覽下載 | 四步：項目與分區 → 選產品 → 列出可編輯的大綱詳細內容 → Canva 生成與匯出 |
| 方案頁 | 產品可連續排列；超過 10 項只提示分區 | 以分區為主要結構。每個分區先有自己的平面圖或空間參考，再接該區產品頁 |
| 產品頁內容 | 圖、名稱型號、規格、數量、報價資訊、圖冊補充圖 | 另加可編輯的展示名稱、描述、賣點，以及市場價、項目優惠價兩個展示價 |
| 簡報模組 | 固定五段：封面、公司介紹、平面圖、方案、參考案例 | 在五段上補公司資質、服務介紹。這兩段與公司介紹一樣用公司固定素材，不逐份重填 |
| AI 效果圖 | FDS-13 為 P2，只在 BWF 正式報價單 | 本階段不擴大。完整 AI 場景效果圖流程暫緩，不進本版驗收 |
| 報價單行距 | 沿用 [報價單-PDF排版-PRD.md](./報價單-PDF排版-PRD.md) | 加大 Item 與下一個 Item 之間的空隙，並加分隔線。見第 9 章 |
| PM 快速報價 | FDS-08 套餐計價為 P1，現有 pitching 快速報價保留 | 維持。轉寫末段提到暫緩，範圍不清楚，不得理解成取消快速報價 |

## 2. 已拍板

| 議題 | 決定 |
|---|---|
| 生成時機 | 不得在只選完產品後就呼叫 Canva。先列出即將生成的大綱詳細內容，使用者改完這份大綱，再生成 |
| 簡報與報價單 | 分開輸出。報價單保持正式報價；簡報做展示、方案說明和公司實力。不把完整簡報內容併入報價 PDF |

| 分區數量與名稱 | 可新增、刪除、調整順序。名稱可改，不限 A／B／C／D。辦公室、會議室或自訂名稱都可以 |
| 分區內容 | 一個分區可有多個產品、多頁簡報，以及該區的平面圖或空間參考圖 |
| 分區粒度 | 不要求每個房間都獨立成一個分區 |
| 人工修改 | 展示名稱、描述、賣點、選用的圖片、兩個展示價，在生成前都可改。AI 產出的文字只是初稿 |
| 描述依據 | 描述要說明對客戶的價值（舒適、靜音、收納、耐用等）。賣點必須能對上產品資料。AI 不得虛構資料裡沒有的功能、材質或認證 |
| 供應商 | 簡報的產品頁不出現供應商、廠家或工廠名稱。公司介紹裡的自設廠房可以保留 |
| 產品圖 | 已有空間場景的高清產品圖直接用。去背、透明，或只有產品本身、沒有場景的圖，先讓其他內容可編輯，再用 Gemini 3.8 生成一張示例圖取代。示例圖不得改成另一件產品的外觀，並標明僅供參考 |
| AI 生成圖 | 生成示例圖，以及報價單「用 AI 生成圖片」，打開時都預設選 Gemini 3.8。仍可改選 Grok 4.7。沒有指定模型的生成請求同樣用 Gemini 3.8 |
| 固定素材 | 公司介紹、資質、服務承諾用公司提供的固定內容，沿用現有 `fds_presentation_company_profile`，不在每份簡報重填 |
| 效果圖範圍 | 本階段不做完整 AI 室內效果圖製作流程。V2.2 的 FDS-13 維持原優先級，不提前、不擴大 |
| 編輯器 | 不做自由拖拉的簡報編輯器。排版仍由 Canva 負責 |

## 4. 簡報四步

入口維持 `/fds/pm/presentation`。現有精靈的四步標題改成下面這四步，不另開第二條簡報流程。

### 4.1 Step 1｜項目資料與分區

填寫這份簡報要用的項目資料，上傳平面圖，建立分區。

| 欄位 | 必填 | 說明 |
|---|---|---|
| 項目名稱 | 是 | 封面使用 |
| 客戶 | 是 | 封面使用。能從現有客戶或報價帶入時帶入，允許改顯示文字 |
| 封面圖 | 否 | 沒有則封面不放主圖，不阻擋後面步驟 |
| 整體平面圖 | 否 | 沒有則簡報略過「項目平面圖」整段，與 V2.2 相同 |
| 分區 | 至少一個才可進入產品已分配完的 Step 3 | 名稱、順序。每個分區可再上傳該區平面圖或空間參考圖 |
| 語言、風格、目的 | 否 | 沿用現有選項，作為 Canva brief 的語氣，不另做一套 |

分區操作：新增、改名、刪除、上移、下移。刪除分區時，已指派到該區的產品改為未分區，不刪產品資料。

尚未選產品時可以先保存分區。沒有任何分區時，Step 3 仍可打開，但大綱裡沒有分區段落；介面說明需要至少一個分區，才能生成。

### 4.2 Step 2｜選擇產品

從現有產品資料庫選擇家具，把每件產品分到一個分區。

- 沿用現有產品搜尋與選品，不新建產品庫。
- 一件產品在這份簡報裡屬於一個分區。改分區只改這份簡報的歸屬。
- 未分區的產品留在清單中，Step 3 的大綱把它們列在「未分區」。生成前必須分完或從大綱移除。
- 產品資料不足（沒有名稱或沒有可用圖片）仍可選入，Step 3 標出缺什麼，不在這裡擋下。

### 4.3 Step 3｜即將生成的大綱

系統把即將送給 Canva 的大綱，按實際頁面逐段列出來。每一段的文字都可以改。改的是這份簡報的大綱，不回寫產品主檔或正式報價。

大綱順序與第 4.4 節送給 Canva 的順序相同：

1. 封面：項目名稱、客戶、封面圖說明。
2. 公司介紹：固定素材的正文，這一份簡報裡可改。
3. 項目平面圖：有整體平面圖才列出，並寫出分區名稱。沒有則這一段不出現。
4. 每個分區一段：分區名稱、該區平面圖或空間參考圖，然後是該區每一件產品。
5. 每件產品一段：展示名稱、型號、產品圖、描述、賣點、市場價、項目優惠價。空的欄位仍列出來，可以補上，也可以留空。
6. 參考案例：已選的案例各一段。沒有選則不出現。
7. 公司資質、服務介紹：固定素材有內容才列出，列出後可改。

供應商、廠家、工廠名稱不出現在任何產品段。

每段可編輯的產品欄位：

| 欄位 | 初始值 | 規則 |
|---|---|---|
| 展示名稱 | 資料庫產品名稱 | 可改。不回寫產品主檔 |
| 型號 | 資料庫型號 | 可改顯示文字。不回寫產品主檔 |
| 描述 | 空，或由「AI 產生初稿」寫入 | 可改。初稿必須能追溯到該產品已有欄位；沒有依據的句子不得寫入 |
| 賣點 | 空，或由同一初稿拆出短句 | 同上。功能、材質、舒適度、設計特點只採用資料裡已有的內容 |
| 市場價 | 空 | 可手填。自動帶入規則未定，見第 5 章 |
| 項目優惠價 | 空 | 可手填。不得把這個展示價寫回 `bwf_quote` 的正式單價 |
| 所屬分區 | Step 2 的選擇 | 可在大綱裡改，該產品段跟著移到新分區 |
| 產品圖 | 資料庫主圖 | 有場景的圖可改用該產品已有的其他圖。沒有背景時，見下方生成示例圖 |

「AI 產生初稿」只寫入該產品段的描述與賣點，不呼叫 Canva，也不生成圖片。使用者可接受、改寫或清空。

大綱裡的文字先列出來、可直接改。沒有背景的產品圖，在這些文字已經列在大綱上之後，才提供「生成示例圖」。選產品的當下不自動生成。

沒有背景是指：去背、透明底，或畫面裡只有產品、沒有空間場景。已有場景的圖不另生成，直接放在該產品段。

生成示例圖使用 Gemini 3.8，可改選 Grok 4.7。參考圖用這件產品已有的圖，讓示例圖保持該產品的外觀，只補上展示用的場景。結果只存在這份大綱，不回寫產品主檔。圖上標明僅供參考。使用者可再改該段文字後重新生成。生成失敗時保留原圖與已改的文字，可重試。

返回上一步改了分區或產品後，大綱按新的選擇重列。仍留在大綱裡的同一件產品，保留使用者改過的文字。

可以生成的條件：

- 至少一個分區，且每件保留的產品都已分到某個分區段。
- 每件保留的產品段都有展示名稱，以及至少一張可用產品圖。沒有背景且尚未生成示例圖的，不能生成。
- 描述和賣點可以是空的。空則該頁不放這兩段。
- 兩個價格可以是空的。空則該頁不顯示價格，也不用別的價格自動填上。

### 4.4 Step 4｜生成及匯出

用 Step 3 列出並改過的大綱呼叫現有 Canva AI 生成。

畫面要有生成進度。沿用現有階段：解析需求、生成內容、建立 Canva 簡報、完成並預覽。失敗時保留已改的大綱，可重試，不另建一份空白簡報蓋掉大綱。

完成後提供：Canva 預覽（現有縮圖，約 15 分鐘失效）、開啟 Canva 編輯（現有 `edit_url`）、匯出 PPTX 與 PDF。FDS 內不另做簡報頁面編輯器。第 5 章若日後改為在 FDS 右側做部分編輯，再改本步，本版不預做。

送給 Canva 的就是 Step 3 那份改過的大綱：

下列文字交給 AI 生成；選定圖片另行上傳到 Canva 素材庫，畫面顯示素材名稱、對應產品／分區及上傳結果，使用者依清單手動放圖。上傳失敗可使用原圖連結手動上傳；不得把素材庫上傳成功標示為已放入投影片。

1. 封面：項目名稱、客戶、封面圖（有才送）。
2. 公司介紹：固定素材。
3. 項目平面圖：有整體平面圖才有這段，並帶分區名稱；有 AI 俯視效果圖時，以效果圖取代平面圖作主圖。
4. 每個分區：該區封面（分區名稱＋該區平面圖或空間參考圖，有圖才放圖）→ 該區產品頁（展示名稱、型號、產品圖或示例圖、描述、賣點、市場價、項目優惠價；空欄不送）。產品頁不送供應商、廠家或工廠名稱。
5. 參考案例：沿用現有案例選擇。沒有選案例就略過。
6. 公司資質、服務介紹：僅在固定素材有內容時輸出。沒有素材就略過，不生成空白頁。

分區順序等於 Step 1 的順序。一個分區的產品多時可多頁，頁與頁都屬於該分區，不把下一分區的產品插進來。

點數用盡、沒有 `design_generation` 能力、生成失敗的提示，沿用 [FDS-2.1-Canva-AI生成.md](./FDS-2.1-Canva-AI生成.md)，不另寫一套錯誤文案。

## 6. 簡報內容結構

| 模組 | 展示內容 | 資料從哪來 |
|---|---|---|
| 封面 | 項目名稱、客戶、封面圖 | Step 1 |
| 公司介紹 | 公司背景與介紹 | `fds_presentation_company_profile` 既有欄位 |
| 項目平面圖 | 整體布局與分區名稱；有 AI 俯視效果圖時用效果圖 | Step 1 的整體平面圖、AI 俯視效果圖與分區列表。沒有平面圖則整段略過 |
| 分區方案 | 該區平面圖或空間參考圖、產品、圖片、描述、賣點、兩個價格 | Step 3 大綱裡改過的那段 |
| 參考案例 | 過往項目與參考圖 | 現有案例選擇。沒有則略過 |
| 公司資質 | 資質、專業能力、信任背書 | 固定素材。現有 `qualifications` 有內容才輸出 |
| 服務介紹 | 送貨、安裝及其他服務承諾 | 固定素材。現有 `services` 有內容才輸出 |

公司介紹、資質、服務介紹是公司級內容。改一處，之後的新簡報用新內容。已生成的 Canva 檔不回溯改寫。

---

## 7. 分區在簡報中的順序

一份簡報的空間順序是：

1. 整體平面圖與分區名稱（沒有整體平面圖則跳過）。
2. 分區 A 的封面（名稱，以及該區的圖，有才放）。
3. 分區 A 的產品頁，可多頁。
4. 下一個分區重複 2、3。

示例名稱可以是「A 區 · 經理辦公室」，也可以是使用者自訂的任何名稱。示例只說明層次，不表示分區必須用字母代號。

不在分區之下再拆「房間」一層。若一個空間需要單獨介紹，就把它建成一個分區。

## 8. 產品展示欄位

| 欄位 | 要求 |
|---|---|
| 產品名稱、型號 | 讀資料庫，允許只改這份簡報的展示文字 |
| 產品圖片 | 有場景的用原圖。沒有背景的，在其他內容可編輯之後生成示例圖再送出 |
| 產品描述 | 可選。AI 初稿加人工確認。向客戶解釋價值，不堆砌參數 |
| 產品賣點 | 可選。只寫資料能支持的功能、材質、舒適度、設計特點 |
| 市場價 | 可選。參考價。來源未定 |
| 項目優惠價 | 可選。給客戶看的優惠展示。來源未定。不是正式報價單的金額欄 |
| 所屬分區 | 這份簡報內的分區 |
| 供應商 | 不放上簡報 |

規格、數量若資料庫或關聯報價行已有，可附在產品頁，但不是本版新增的必填項。正式數量與金額仍以報價單 PDF 為準。

## 9. 報價單 Item 之間的空隙（P1）

會議說的「報價單行距」是一個 Item 和下一個 Item 之間的空隙，不是同一 Item 裡面文字的行距。正式報價 PDF 瀏覽時，相鄰 Item 的邊界不清楚。本節只拉開這段空隙並加分隔，其餘版式仍以 [報價單-PDF排版-PRD.md](./報價單-PDF排版-PRD.md) 為準。

- 只加大 Item 與下一個 Item 之間的空隙。
- 在這段空隙加上一條清楚、細的分隔線。
- 用這段空隙和分隔線區分相鄰 Item。
- 不改同一 Item 內部的文字行距、圖片間距、規格與說明的間距。
- 標籤、段落、欄位不是 Item，它們之間的間距維持現狀。
- 不以大面積背景色作為 Item 與 Item 的主要區別。表頭淡灰可保留。
- 列印仍要緊湊。不得為了這段空隙把原本可同頁的少量 Item 拆成明顯更多頁。實作時以一份現有多 Item 報價對照改前改後頁數，頁數只允許因內容本身增加，不允許只因 Item 之間的空隙變成將近翻倍。

不在本節改欄位、金額計算、圖片版式或分頁算法的其他規則。

| | 正式報價單 PDF | 方案簡報 |
|---|---|---|
| 用途 | 商務報價 | 方案介紹與銷售展示 |
| 價格 | 完整報價明細 | 市場價、項目優惠價（可空） |

客戶可以同時收到兩份。簡報上的展示價與報價單不一致時，以報價單 PDF 的金額為正式報價。介面不必在簡報上重算報價單。

## 11. 必須沿用的現有能力

| 能力 | 怎麼接 |
|---|---|
| Canva AI 生成 | 仍用 `supabase-functions-generate-canva-presentation`。不恢復 Autofill，不用 PptxGenJS 先做 PPTX 再匯入 |
| 公司介紹 | 仍是 `fds_presentation_company_profile` 一列。資質、服務用既有 `qualifications`、`services`，不另建素材表 |
| 產品讀取 | 列表不得 `.select('*')`。產品圖沿用已上傳到 Storage 的 URL，不把 base64 寫進簡報草稿 |

| 設計專案分區 | `ProjectPartitionPanel` 仍服務設計專案。簡報分區只存在這份簡報草稿，不自動寫入該面板 |
| 權限 | 沿用現有簡報與報價角色，不新增角色 |

簡報草稿若需要新欄位存放分區、展示文案和兩個價格，只加在簡報自己的 session／草稿上。不改 `products` 主檔，不改報價明細的計價欄位。

## 12. 驗收

簡報：

- 四步順序為項目與分區、選產品、列出可編輯的大綱、生成匯出。大綱上的文字有改，生成就用改過的文字。
- 分區可增刪改名和調順序；名稱不必是 A／B／C／D。
- 生成結果的產品出現在所屬分區之下，不先把全案產品排成一串再補分區。
- 沒有整體平面圖仍能生成，且沒有空白的平面圖段。
- 簡報產品頁沒有供應商、廠家或工廠名稱。
- 有場景的產品圖直接使用。沒有背景的產品圖，要等該產品段已經列在大綱上、文字可編輯之後，才生成示例圖。還沒有示例圖時，不能開始 Canva 生成。
- 示例圖保持該產品外觀，並標明僅供參考。
- 描述初稿不會寫出產品資料沒有的功能或認證；使用者改過的文字會進入生成內容。
- 手填的市場價、項目優惠價只出現在簡報，正式報價單金額不變。
- 價格或描述留空時，該頁不顯示對應區塊，仍能生成。
- 生成失敗後草稿還在，可重試。
- 完成後可預覽、打開 Canva、匯出 PPTX 或 PDF。
- 指定圖片上傳至 Canva 素材庫，對應清單可辨認產品／分區；失敗時顯示提示並可開啟原圖。使用者在 Canva 手動放圖後核對圖片與產品一致，再匯出。
- 公司資質或服務素材為空時，不出現空白頁。

報價單 PDF：

- 相鄰 Item 能靠兩者之間的空隙和分隔線分開，而不是靠整行底色。
- 同一 Item 內部的文字行距與改前一致。標籤、段落、欄位的間距與改前一致。
- 欄位、金額、圖片規則與改前一致。
- 用一份既有的多 Item 報價對照，頁數沒有只因 Item 之間的空隙明顯增加。

不在本版驗收：指定圖片自動放入 Canva 頁面、價格自動帶入、FDS 內簡報頁編輯、FDS-13 完整室內效果圖。

## 13. 不在本版

- 指定圖片自動放入 Canva 對應頁面。

- 完整 AI 室內效果圖、按透視圖生成可拖拽場景，以及其他 FDS-13 範圍。
- 把示例圖畫成另一件產品的外觀，或把它回寫成產品主檔原圖。
- 把簡報展示價寫進正式報價單，或用簡報取代報價 PDF。
- 自由拖拉簡報編輯器。
- 取消或重寫 PM 快速報價。
- 改寫 V2.2 其餘 P0／P1 模組的驗收。
