# Furniture 1000 功能描述

最後更新：2026-10-14

本文件給系統設定的「PRD功能描述」使用。它說明 Furniture 1000 現有模組，方便日後對照版面與修正邏輯。逐頁說明放在 `docs/prd/`，系統級說明放在倉庫根目錄的 `README.md` 與 `CLAUDE.md`。

## 主流程

1. **設計師選傢俬 / 廠家目錄**：瀏覽產品類型、PDF、常用傢俬與模型。
2. **傢俬報價**：由 pitching 建立快速報價，明細寫入 `bwf_quote_item`，報價單號沿用 PMS pitching code。
3. **產品管理**：上載報價 PDF、整理待處理產品與產品目錄。圖片先上傳 Storage，列表查詢不可讀取 base64 圖片欄位。
4. **網上發布**：產品文案 → 產品價錢 → 傢俬組檢查 → 準備上載 → 已上載。退回文案時保留 `ready_to_shopify` 列，只重置流程旗標。
5. **客戶專區**：客戶查看報價方案、產品搜尋、訂製、付款送貨與訂單狀況。

## 系統設定

系統管理員可使用：

- **用戶管理 / 登入紀錄**：平台帳戶與登入活動。
- **Shopify 分類 / 產品分類**：發布與目錄分類。
- **系統設定**：Shopify 連線與 AI 模型偏好。
- **電郵通知**：通知設定。
- **PRD功能描述**：唯讀顯示本倉庫 Markdown。
- **每日指令記錄**：開發指令的開始／完成時間、狀態、Token、Credit 與工具成本（USD）。
- **開發成本**：以香港時間彙總已完成指令工時，套用港元時薪；工時成本（HKD）與工具成本（USD）分開顯示。

## 資料邊界

- 報價 header 在 `bwf_quote`，明細在 `bwf_quote_item`。
- 開發指令與時薪版本只供系統管理員經 RPC 讀寫，前端不可直接改表。
- 時薪版本只新增、不覆寫舊版本。未有適用費率的工時標示為未定價。
